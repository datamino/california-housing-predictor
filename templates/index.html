About this Predictor

This application predicts house prices in California based on various features including geographical location, property characteristics, and demographic information.

Model Information

The prediction model is trained on the California Housing dataset, which contains information from the 1990 California census. The model uses a machine learning algorithm to predict median house values based on the input features.

How to Use
  1. Go to the "Price Prediction" tab
  2. Adjust the input features to match your house specifications
  3. Click the "Predict House Price" button to get an estimate
  4. Explore the "Data Visualization" tab to understand pricing trends
Data Privacy

This application does not store any user input data. All predictions are generated locally in your browser session.
